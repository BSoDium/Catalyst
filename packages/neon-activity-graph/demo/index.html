A year of activity drawn as glass blocks: lit like neon tubes in the dark theme, and in the light theme the same glass with the tubes switched off, lit by the sun. A three.js component with a React wrapper.Check out the software page of BSoDium’s Catalyst.Theme

GitHub contributionsWakaTime coding time

How it works

  • Data. Two daily series from any source, one number a day each: here GitHub contributions on top, WakaTime coding time below.
  • Rendering. Glass blocks refract the ground. In the dark theme each block holds a neon-tube rod that lights the glass and the ground; in the light theme the tubes are off and the glass is lit by the sun, whose coloured shadows and caustics through it are traced on the GPU.
  • Start-up. In the dark theme the tubes flicker on like a gas sign, with a synthesised hum, and a bell rings when the colours change. The light theme is silent. Skipped for reduced motion.
  • Cost. Drawn progressively once, then idle. A lite mode for weak devices. About 33 KB gzipped (plus 42 KB of baked light, dark theme only); three.js is yours.
