Neon-activity-graph

A year of activity as glass blocks lit like neon tubes: three.js, light and dark, a React wrapper. Used on the software page of Catalyst, Elliot’s portfolio.

One glass block a day, over the last year.

How it works

  • Data. Two daily series from any source, one number a day each: here GitHub contributions on top, WakaTime coding time below.
  • Rendering. Glass blocks refract the ground. In the dark theme each block holds a neon-tube rod that lights the glass and the ground; in the light theme the sun's caustics through the glass are traced on the GPU.
  • Start-up. In the dark theme the tubes flicker on like a gas sign, with a synthesised hum. Skipped for reduced motion.
  • Cost. Drawn progressively once, then idle. A lite mode for weak devices. About 33 KB gzipped (plus 42 KB of baked light, dark theme only); three.js is yours.
